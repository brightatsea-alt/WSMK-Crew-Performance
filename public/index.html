1. 승선이력 스크린샷 / PDF

붙여넣기(Ctrl+V) · 드래그 · 파일 선택 · 여러 장 가능
🖼️
스크린샷을 붙여넣기 Ctrl+V 하거나 파일을 드래그하세요
여러 선원을 한 번에 — 선원별 승선이력 스크린샷을 여러 장 올리거나 PDF(여러 페이지)를 올리면 선원별로 각각 분석해 아래에 차례로 나열합니다.
PNG / JPG / PDF · 선박명 + 승선/하선일이 보이는 선원 경력 표 · 같은 선원의 페이지가 여러 장이면 이름으로 자동 합칩니다
＋ 다른 선원의 스크린샷/PDF를 계속 붙여넣거나 드래그하면 목록에 추가됩니다.
직책 지정 스크린샷에 이름·직급 등 개인정보가 없을 때 — 여기 입력한 직책이 추출 결과에 적용됩니다

2. 승선 기간 확인

선원별 추출 결과를 확인·수정 후 조회 · 승선 기간 = Type/Status에 'On Board'가 포함된 행(예: On Board (o.o.s))의 Start Date ~ End Date만 적용
스크린샷/PDF를 분석하면 선원별 승선 기간이 여기에 표시됩니다. 직접 입력도 가능합니다.
